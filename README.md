# 📖 Overview

**SocietyHub** is a desktop-based **University Society Management System** developed using **C# and Windows Forms**, with **MySQL** as its database.

The system provides a centralized platform for managing university societies, students, events, memberships, venues, sponsors, registrations, announcements, and feedback.

The project demonstrates the practical application of **Object-Oriented Programming, Database Management, CRUD operations, and layered application design**.

# 🗄️ Database

SocietyHub uses **MySQL** to store and manage the system's relational data.

**MySQL Workbench** was used for database design, development, and management.

The application follows a layered approach, with separate **Business Logic (BL)** and **Data Logic (DL)** components to organize application operations and database interaction.

# 🚀 Getting Started

### Open the project

Open:


> **Note:** The MySQL database must be configured before running the application.
