# 📖 Overview

**SocietyHub** is a desktop-based **University Society Management System** developed using **C# and Windows Forms**, with **MySQL** as its database.

The system provides a centralized platform for managing university societies and their activities, including students, events, memberships, venues, sponsors, registrations, announcements, and feedback.

The project combines **Object-Oriented Programming (OOP)**, **Database Management Systems (DBMS)**, CRUD operations, and layered application design to create a complete management system.

# 🗄️ Database

The system uses **MySQL** to store and manage interconnected data for the university society ecosystem.

The database covers major entities such as:

* Students
* Societies
* Society Categories
* Events
* Event Categories
* Venues
* Sponsors
* Sponsorships
* Memberships
* Registrations
* Announcements
* Feedback

**MySQL Workbench** was used for database development and management.

📁 Database scripts and related documentation can be found in the repository.

# 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Meerab786/SocietyHub.git
```

### Open the Project

Open:

```text
SocietyHub.sln
```

using **Visual Studio 2026**.

### Configure the Database

Set up the required **MySQL database** and update the application's database connection settings.

### Run

Build the solution and press **F5** or click **Start** to launch the application.
